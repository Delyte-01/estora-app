# Next.js 16 Starter

Next.js 16 · TypeScript · Tailwind CSS v4 · shadcn/ui · GSAP · Lenis

```bash
npm install
npm run dev
```

Open http://localhost:3000

- `src/components/smooth-scroll.tsx` – Lenis synced with GSAP ScrollTrigger
- `src/components/hero.tsx` – GSAP timeline + shadcn buttons
- `src/components/feature-cards.tsx` – ScrollTrigger reveal + shadcn cards

Add more shadcn components: `npx shadcn@latest add dialog`
